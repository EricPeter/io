01 — Production RAG with Citations

02 — Cost-Optimized Model Router

Routes every query to the cheapest model that can handle it — Haiku for simple questions, Sonnet for medium, Opus for complex reasoning. Tracks cost per request in SQLite and exposes real-time Prometheus metrics. Saves up to 10× on API costs.

FastAPI Prometheus Anthropic SDK SQLite

03 — Multi-Agent Research System

A CrewAI pipeline where a Researcher, Writer, and Fact-Checker collaborate on research reports. The Fact-Checker marks uncertain claims with [UNCERTAIN] markers and pauses for human approval before finalisation. Every agent action is written to a tamper-evident JSONL audit trail.

CrewAI Anthropic SDK Audit Trail

04 — Automated Eval Harness

Runs 20+ golden Q&A test cases against a RAG system before every deploy. Uses DeepEval for answer relevancy and hallucination scoring. Blocks CI/CD pipelines if quality drops below threshold. Tracks eval scores over time to surface regressions.
